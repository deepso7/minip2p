What does the stream caller have to remember?

Compare owned chunks with partial writes and pull reads. Both sketches use an 8-byte send buffer, an 8-byte receive buffer, and a 4-byte drive step. Pause the reader, fill the buffers, or read only part of a notification. Watch who owns the remaining bytes and who must resume work.

This is an in-memory contract model. It does not run minip2p, QUIC, or TCP, and it does not measure speed or allocations. The Rust companion runs the same kinds of cases. The owned sketch borrows today's interface shape; it does not reproduce today's transport internals.
