# TCP is a direct path wherever QUIC is

QUIC is `std`-only, so a device with no operating system has only TCP. Every place that selects, announces or binds direct addresses therefore treats TCP as a first-class direct path alongside QUIC; leaving it out anywhere would make such a device discoverable yet unreachable, or able to call out but never be called back.

- **Direct candidates include TCP.** `select_direct_addrs` (`minip2p-core` `candidates.rs`) keeps TCP addresses alongside QUIC. This selector feeds the whole NAT agent, so dropping TCP here would leave such a host advertising nothing to dial and never being dialed back.
- **A direct candidate is a whole, dialable transport address with no `/p2p` suffix.** A circuit address is excluded because it is reached by dialing the relay and asking it to connect, not by dialing the address; an address carrying a peer id belongs in a `PeerAddr`, not a transport candidate.
- **A circuit's relay leg may be QUIC or TCP.** `Multiaddr::is_relay_circuit_transport` accepts either: a circuit rides an established connection to the relay, so how that connection was made is the relay's business. HOP and STOP are ordinary streams on that connection, so a TCP relay carries circuits exactly like a QUIC one. The leg must still be a whole transport address (not a bare host or `/udp` without `/quic-v1`), since reaching a circuit means dialing the relay.
- **Discovery beacons announce TCP.** `BeaconAgent` (`minip2p-discovery`) publishes every dialable TCP listen address alongside QUIC ones.
- **mDNS advertises every listener, TCP included,** with a wildcard host replaced by the interface's own address and everything after the host carried through untouched, the same substitution a QUIC listener gets.
- **An FFI listen address picks the transport it binds.** A foreign runtime that hands `P2pEndpoint` a `/tcp` listen address gets a TCP listener and reports TCP listen addresses. Parsing `/tcp` peers for dialing while binding only QUIC was rejected: a TCP-only device could call out but never be called, and the address it reported would name a socket it does not have. `a_tcp_listen_address_binds_tcp_and_is_dialed_over_it` in `crates/ffi/tests/loopback.rs` covers it.
