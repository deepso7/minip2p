# What the wire_inputs fuzz target asserts, and how it reaches deep paths

`fuzz/fuzz_targets/wire_inputs.rs` is more than a crash finder; several of its assertions are oracles, and its setup is shaped to get attacker bytes past the first decoder:

- **Independent oracles.** Multiaddr classification is checked against the protocol slice directly (`expected_transport_kind`), not through the helpers `transport_kind` is built from, or the assertion would be entailed by the implementation and could never fail. The WebTransport shape rule is quic-v1, webtransport, then only certhashes. Anything that decodes must re-encode and re-print identically: a decoder accepting a shape the encoder cannot reproduce is a round-trip hole.
- **Unreachable-state assertions.** An unauthenticated secure-mux peer must never reach the established state from arbitrary bytes; establishing is gated on decrypting an AEAD-protected Yamux selection under a key derived from statics the harness never puts on the wire, so a hit is the defect itself, not a lucky mutation.
- **Ping invariants.** The responder only ever echoes a complete payload the peer sent; the outbound side measures an RTT only when the reply echoes what was sent, otherwise it is refused rather than returning to idle.
- **Reaching deep paths.** A valid fragmented multistream-select exchange advances both roles into the Noise decoder before fuzzed bytes begin; pubsub runs after a valid meshsub setup; the AutoNAT server gets a well-formed DIAL from the authenticated requester carrying fuzzed addresses, so the observed-IP filter and forwarding run (raw bytes almost never name the requester's peer id). Stream decoders are fed in two chunks to exercise incremental paths. Peer TLS certificates are treated as attacker-controlled X.509 DER.
- **WebTransport client harness.** The fuzzed server mostly offers the dialed certhash, sometimes no extensions or a hash-free list, which the client must reject. The honest responder is built lazily on the first handshake round to skip key setup on inputs that never pump. It polls one more time than there are ops so the last op's effects are checked, asserts grants never let the platform deliver past the flow-control window, and steps time past the reset grace with small steps and the handshake timeout with large ones.
