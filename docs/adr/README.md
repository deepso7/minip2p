# Architecture decision records

One decision per file, numbered in the order they were made. Number 0015 was never used.

0034 to 0119 record earlier implementation decisions after the fact, grouped by area rather than by date: core and identity (0034–0036), secure-mux (0037–0038), TCP (0039–0043), QUIC (0044–0050), WebTransport (0051–0056), transport set and circuits (0057–0059), swarm (0060–0064), protocols and mDNS (0065–0072), NAT (0073–0080), relay server and mesh (0081–0083), the Endpoint (0084–0090), bindings (0091–0100), examples and docs (0101–0104), and tests, benches and infrastructure (0105–0119).
