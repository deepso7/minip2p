# Change recipes

Where a cross-layer change lands, and the narrowest check that covers it. Skip the touch points marked "if" when they do not apply. Finish with `just test` and `just clippy full`; `just bindings-check` ends by requiring a clean `git status`, so commit before running it.

| Change | Touch | Check |
| --- | --- | --- |
| Endpoint capability or Cargo feature | The feature in `crates/minip2p/Cargo.toml`, and a row in `scripts/run-feature-matrix.sh` (plus `scripts/check-targets.sh` if it builds for no_std or has docs). If it is a capability: its protocol crate; `Capabilities`, `validate` and `install` in `crates/minip2p/src/setup.rs`; its place in `Engine::drive` (`engine.rs`, whose order is load-bearing); its builder setters; `crates/ffi-core/src/config.rs` if bindings expose it. | `just matrix clippy <row>`, `just matrix test <row>`; `just check-nostd` if portable; `just docs` if documented |
| `EndpointEvent` variant | `SwarmEvent` (`crates/swarm/src/events.rs`) and `EndpointEvent::from_swarm` if the swarm raises it; `EndpointEvent` (`crates/minip2p/src/portable/event_stream.rs`). If bindings expose it: `P2pEvent` and `convert_endpoint_event` (`crates/ffi-core/src/events.rs`); `P2pEvent`, `P2pEvent_Tags` and `Minip2pNamedEventMap` in `bindings/ts/core/src/types.ts`, and `SDK_EVENT_NAMES` in `sdk.ts`; if it names a connection, the carry's elision rules (`crates/ffi-core/src/carry.rs`, `UNSEEN_CONNECTION_TAGS` in `sdk.ts`); `pnpm rn:generate`, and `ENUM_FIELDS` in `bindings/ts/react-native/src/adapter.ts` if it carries a flat enum. | `cargo test -p minip2p-ffi-core`, `just bindings-check` |
| Binding method | The `Endpoint` method (`crates/minip2p`); `P2pEndpoint` (`crates/ffi-core/src/endpoint.rs`); the forwarders in `crates/ffi/src/endpoint.rs`, `crates/nodejs/src/lib.rs`, and `crates/web/src/{host,wasm}.rs`; `Minip2pBackend` in `bindings/ts/core/src/backend.ts` and `sdk.ts`; `SerdeEndpoint` / `SerdeBackend` in `serde-backend.ts` (shared by Node and Web); `pnpm rn:generate` and the React Native adapter; `bindings/ts/test-fixtures/src/adapter-contract.ts`. | `just bindings-check`, `just check-wasm` |
| Binding config field | The Rust builder setter it maps to; `EndpointConfig` in `crates/ffi-core/src/config.rs`; `Minip2pConfig` in `bindings/ts/core/src/types.ts`, and `BackendEndpointConfig` / `resolveEndpointConfig` in `config.ts`, which Node and Web pass to their native constructors; `pnpm rn:generate` and `nativeEndpointConfig` in the React Native adapter. | `just bindings-check` |
