## Install

<Tabs>
  <Tab title="Rust">

    ```bash
    cargo add minip2p-rs
    ```

  </Tab>
  <Tab title="Node.js">

    ```bash
    npm install @minip2p/node
    ```

  </Tab>
  <Tab title="React Native">

    ```bash
    npm install @minip2p/react-native
    ```

  </Tab>
</Tabs>

minip2p opens authenticated QUIC and TCP connections from Rust, Node.js, and
React Native. On `no_std + alloc`, TCP runs through a pluggable provider and
`Endpoint::portable`. The Rust `Endpoint` is synchronous and caller-driven,
with no async runtime. The TypeScript SDK owns its native driver and presents
typed events, cancellable Promises, and `Stream` handles on Node.js and React
Native.

<Tabs>
  <Tab title="Rust">

    ```rust
    use minip2p::{Deadline, Endpoint};

    fn main() -> Result<(), minip2p::Error> {
        let mut node = Endpoint::builder()
            .agent_version("my-app/0.1.0")
            .bind_quic("127.0.0.1:0")?;

        println!("listen={}", node.listen()?);

        while let Some(event) = node.next_event(Deadline::NEVER)? {
            println!("{event:?}");
        }

        Ok(())
    }
    ```

  </Tab>
  <Tab title="Node.js">

    ```ts
    import {
      Minip2p,
      generateSecretKey,
    } from "@minip2p/node";

    const endpoint = Minip2p.create({
      secretKey: generateSecretKey(),
    });

    console.log(endpoint.peerId(), endpoint.listenAddrs());
    endpoint.close();
    ```

  </Tab>
  <Tab title="React Native">

    ```ts
    import {
      Minip2p,
      generateSecretKey,
    } from "@minip2p/react-native";

    const endpoint = Minip2p.create({
      secretKey: generateSecretKey(),
    });

    console.log(endpoint.peerId(), endpoint.listenAddrs());
    endpoint.close();
    ```

  </Tab>
</Tabs>

Optional capabilities add custom streams, NAT traversal, pubsub, signed peer
discovery, and local-link mDNS.

## Constraints

| | |
| --- | --- |
| <Badge>pre-1.0</Badge> | APIs may change before the first stable release. |
| <Badge>QUIC and TCP</Badge> | The dial address picks the transport. WebSocket and WebTransport are out of scope. |
| <Badge>no_std + alloc</Badge> | Protocols, orchestration, and TCP work without an OS; you supply I/O, time, and entropy. |
| <Badge>QUIC-only punching</Badge> | DCUtR hole punching needs QUIC; a TCP-only peer reaches NATed peers through a relay. |
| <Badge>Rust 1.91+</Badge> | Workspace MSRV. |
| <Badge>Caller-driven Rust</Badge> | Rust applications drive progress; the Node.js and React Native adapters own their native drivers. |
| <Badge>Relay client</Badge> | Bring a Circuit Relay v2 server when a relayed path is required. |
