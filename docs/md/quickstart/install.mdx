---
title: Install
description: Install minip2p for Rust or React Native and prepare the required native toolchains.
---

Choose the application surface you are building. Rust applications install the
facade crate from crates.io. React Native applications install the native SDK
from npm.

## Rust

minip2p requires **Rust 1.88 or newer**. The application-facing crate is
published to crates.io as `minip2p-rs` and imported in Rust code as `minip2p`.

### Add the dependency

<Tabs>
  <Tab title="cargo add">

    ```bash
    cargo add minip2p-rs
    ```

  </Tab>
  <Tab title="Cargo.toml">

    ```toml
    [dependencies]
    minip2p-rs = "0.2.0"
    ```

  </Tab>
</Tabs>

The base crate includes QUIC, mutual peer authentication, Identify, Ping, and
registered application protocols.

### Choose optional features

Features expose APIs at compile time. Builder methods decide which drivers run
inside a particular endpoint.

<Tabs>
  <Tab title="NAT">

    ```toml
    minip2p-rs = {
      version = "0.2.0",
      features = ["nat"]
    }
    ```

    Then activate the NAT driver with `.relay(...)`,
    `.autonat_server(...)`, or `.nat_config(...)`.

  </Tab>
  <Tab title="Pubsub">

    ```toml
    minip2p-rs = {
      version = "0.2.0",
      features = ["pubsub"]
    }
    ```

    Then activate pubsub with `.pubsub()` or `.pubsub_config(...)`.

  </Tab>
  <Tab title="Discovery">

    ```toml
    minip2p-rs = {
      version = "0.2.0",
      features = ["discovery"]
    }
    ```

    The `discovery` Cargo feature includes the `nat` and `pubsub` APIs.
    Calling `.discovery()` or `.discovery_config(...)` activates discovery,
    default pubsub, and the NAT agent together. Use
    `.peer_discovery_config(...)` to tune the shared peer book and automatic-dial
    policy.

  </Tab>
  <Tab title="mDNS">

    ```toml
    minip2p-rs = {
      version = "0.2.0",
      features = ["mdns"]
    }
    ```

    The `mdns` Cargo feature includes the `nat` APIs but does not include
    pubsub. Calling `.mdns()` or `.mdns_config(...)` activates local-link
    multicast discovery and the shared peer book. Use
    `.peer_discovery_config(...)` to tune that book and its automatic-dial
    policy.

  </Tab>
</Tabs>

:::warning
`.autonat_server(...)` by itself enables reachability probing, not a complete
traversal path. Configure a relay when the endpoint must establish relayed
connections or perform relay-assisted hole punching.
:::

### Compiled is not enabled

| Cargo selection | Builder activation | Result |
| --- | --- | --- |
| Base | None required | QUIC, Identify, Ping, custom protocols |
| `features = ["nat"]` | `.relay`, `.autonat_server`, or `.nat_config` | NAT driver runs with the supplied capabilities |
| `features = ["pubsub"]` | `.pubsub` or `.pubsub_config` | Gossipsub or floodsub driver runs |
| `features = ["discovery"]` | `.discovery` or `.discovery_config` | Discovery, default pubsub, and NAT coordination run |
| `features = ["mdns"]` | `.mdns` or `.mdns_config` | Local-link mDNS, shared discovery-book, and NAT coordination run |

See the [feature matrix](/reference/feature-matrix) for the methods, events,
and infrastructure each option adds.

### Check the Rust installation

```rust
use minip2p::Endpoint;

fn main() -> Result<(), minip2p::Error> {
    let node = Endpoint::builder().bind_quic("127.0.0.1:0")?;
    println!("local peer: {}", node.peer_id());
    Ok(())
}
```

Run it with:

```bash
cargo run
```

The endpoint generates an ephemeral Ed25519 identity when no identity is
provided. Continue to [Connect two peers](/quickstart/connect-peers).

## React Native

### Add the package

<Tabs>
  <Tab title="npm">

    ```bash
    npm install @minip2p/react-native
    ```

  </Tab>
  <Tab title="pnpm">

    ```bash
    pnpm add @minip2p/react-native
    ```

  </Tab>
  <Tab title="yarn">

    ```bash
    yarn add @minip2p/react-native
    ```

  </Tab>
  <Tab title="bun">

    ```bash
    bun add @minip2p/react-native
    ```

  </Tab>
</Tabs>

The adapter is a native package, not a JavaScript-only library. It requires
React Native's New Architecture and Hermes.

| Toolchain | Current requirement |
| --- | --- |
| React Native | 0.85, New Architecture, Hermes |
| Node.js | 22 or newer |
| Android | SDK 36 and NDK 28.2.13676358 |
| iOS | Xcode 26 and deployment target 15.1 or newer |

### Create a development build

After adding the package, rebuild the native application so React Native can
autolink its TurboModule and bundled Rust libraries. **Expo Go is not
supported** because it cannot load custom native code.

Expo SDK 56 applications should use `expo-dev-client`:

```bash
npx expo install expo-dev-client
npx expo prebuild
```

Then build and start the target platform:

<Tabs>
  <Tab title="iOS">

    ```bash
    npx expo run:ios
    npx expo start --dev-client
    ```

  </Tab>
  <Tab title="Android">

    ```bash
    npx expo run:android
    npx expo start --dev-client
    ```

  </Tab>
</Tabs>

Bare React Native applications can use their normal iOS or Android build after
installing the package. Ensure the project uses the required deployment target,
SDK, and NDK versions above.

### Local-network permissions

Only applications that enable mDNS need local multicast setup.

<Tabs>
  <Tab title="iOS / Expo config">

    ```json
    {
      "ios": {
        "infoPlist": {
          "NSBonjourServices": ["_p2p._udp"],
          "NSLocalNetworkUsageDescription": "Discover nearby peers."
        }
      }
    }
    ```

  </Tab>
  <Tab title="Android manifest">

    ```xml
    <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
    <uses-permission android:name="android.permission.CHANGE_WIFI_MULTICAST_STATE" />
    ```

  </Tab>
</Tabs>

Continue to [Start with React Native](/guides/react-native/start).
